# Упаковка Float64 через FJCVTZS и переезд на Rust 1.99

Родитель: `f40b4f8a`. Тулчейн: rustc 1.99.0 (stable обновился 2026-10-15).

## Изменения

- Graph-тир ARM64 `emit_box_float64`: на CPU с `FJCVTZS` один
  `fjcvtzs w16` + `b.ne` доказывает Int32-кодировку (флаг Z выставлен
  ровно для int32, отличного от −0) вместо `fcvtzs`/`scvtf`/`fcmp` и
  отдельной проверки −0. Без расширения остаётся прежняя последовательность.
  Тег Number ставится одним `orr` с логическим immediate; лишний `mov w16, w16`
  удалён. NaN-канонизация и смещение double не изменились; x86 не тронут.
- Новый тест `optimized_float64_boxing_matches_canonical_number_bits`:
  результаты оптимизированного кода побитно равны `Value::number_f64` на
  краях Int32, ±0, NaN, субнормалях, бесконечностях и значениях,
  переполняющих Int32.
- Новый корпус `number_boxing.js`: арифметика и phi в return, поля,
  элементы массива, ключи Map, coercion и исключения без повторов.
- Rust 1.99: исправлены новые линты (`chunks_exact` → `as_chunks`,
  `fetch_update` → `try_update`, одиночный диапазон в тестах).
- Rust 1.99 вскрыл UB в тестовой фикстуре VM: окно слотов публиковалось
  в кадр сырым указателем, а затем читалось через `&mut`-заимствование,
  которое компилятор кэшировал через вызов (сборщик переписывает слоты
  через кадр). Фикстура теперь читает только через опубликованный указатель.
  На 1.96 тот же исходник проходил; движок не затронут.
- `boxed_immediates_accept_numbers_without_repeated_deopts` падал и до
  слайса: после трекинга типов полей запись 1.5 генерализует Int32-поле и
  инвалидирует зависимые тела. Тест переписан на текущий контракт: не более
  двух выходов на функцию, точный результат, оптимизированный цикл (на x86
  тела инлайнятся в OSR-тело цикла).

## Гейт

- Clippy host/x86 с `-D warnings`; VM 1272; JIT ARM64 292 / x86_64 315;
  runtime 16/6/6/3 на обеих архитектурах; regex 86 на обеих.
- Difftest 176/176 на обеих архитектурах.
- Test262 `full-2026-10-15d.json`: 53575 / 52463 pass / 12 fail / 1100 skip,
  0 timeout; набор падений совпадает с 15c.
- Oracle 84 сравнения с Node (12 корпусов × 7 режимов), GC 26, full-GC 54.
- Checked GC: 8448/8448 (176 корпусов × 16 страйдов × 3 тира) с первого
  прогона, без повторов. Координатор завершился ошибкой на финальной
  сверке freeze: после запуска изменён только тест
  `jit_boxed_arithmetic.rs`, который checked CLI не компилирует; хэш бинаря
  не изменился. Все исходные строки сохранены.
- Попытки clippy-host-1, vm-lib-2 и runtime-boxed-arithmetic-x86-1 упали
  по причинам выше и перезапущены после исправлений.

## Замеры

3 раунда × 5 повторов, порядок parent/current/Node ротируется.
Parent собран прежним rustc, поэтому дельта включает смену компилятора.

| Нагрузка | parent, с | current, с | Node, с | current/parent по раундам |
|---|---|---|---|---|
| raytrace | 1.306 | 1.237 | 0.559 | −7.5%, −7.6%, −3.0% |
| box2d | 0.857 | 0.849 | 0.312 | −3.2%, −1.7%, −0.4% |
| navier-stokes (контроль) | 0.914 | 0.924 | 0.719 | +1.5%, +1.3%, −0.8% |

Инструкции (диагностика): raytrace −1.56%, box2d −1.51%,
navier-stokes −0.15%. Микротест упаковки (~35 мс на процесс) отвергнут:
время определяется стартом.
