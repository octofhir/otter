# RegExp: один буфер захватов на массовый поиск

Замены с захватами: **−15,53…−15,96% wall**, инструкции **−6,78%**, контроль Node **0,69%**. Подтверждённый повтор без групп: **−21,87…−22,12% wall**, контроль Node **1,59%**. Одиночные exec/test не имеют установленного выигрыша.

База: `7d1f3c36`. Полная wall-матрица: наблюдаемое геосреднее времени Otter **+0.97%**, FW **+0.10%**. Контроль Node/Bun изменился от **-24.14% до +35.35%**, геосреднее Node **+0.48%**.

Полная матрица не проходит заранее установленный критерий стабильности; широкие wall-дельты сохранены как наблюдения с `scoreable: false`. Общий wall-выигрыш не установлен.

## Механизм

Удалены `Vec<Match>` с отдельным буфером captures и `Arc`-clone имён на каждое совпадение массового поиска. Один `MatchBatch` хранит плоские строки исходных слотов; таблица имён захватов удерживается один раз на успешную серию. Borrowed `Match`/`Captures` читают эти строки без промежуточной коллекции. Lending-поиск и оба способа сбора используют один matcher, его native/interpreter scratch и прежний учёт backtrack work. Старые внутренние API и неиспользуемые aliases удалены, все потребители переведены в этой правке.

Одиночные exec/test используют `MatchRecord`: общий диапазон хранится прямо, captures декодируются один раз для повторных чтений при построении JS-результата. Шаблон без групп не выделяет буфер диапазонов. Массовый replace, включая ограниченную одним совпадением неглобальную замену, собирает свой batch непосредственно из matcher scratch. Это устраняет промежуточное преобразование одиночного результата в коллекцию.

Native scratch может сохранять ёмкость от более широкого шаблона; в результат попадает только точный prefix текущего program.capture_slot_count(). Служебные progress marks циклов остаются за этой границей. Владение всеми диапазонами завершается до callbacks и VM-аллоцирования. Legacy statics выбирают первые девять captures и последний участвовавший capture за один проход. Source width, lastIndex, duplicate names, indices identity и abrupt completion сохранены.

## Локальные сценарии

Три серии с изменением порядка, по пять запусков parent/current/Node. Все процессы завершились успешно, вывод совпал с Node. Все 225 исходных samples сохранены в performance.json. Локальное наблюдение требует разброса контрольной медианы Node не более 5% и отсутствия зарегистрированной активности компилятора в интервале сценария.

| Сценарий | Δ wall по трём сериям | Δ инструкций | Разброс Node | Статус |
|---|---:|---:|---:|---|
| many-captures | -15.88%, -15.53%, -15.96% | -6.78% | 0.69% | локальное наблюдение |
| no-captures | -18.88%, -21.13%, -5.23% | +8.73% | 4.80% | не оценивается |
| test-hit | +0.45%, -10.79%, +0.12% | +3.84% | 15.83% | не оценивается |
| test-miss | +0.23%, -0.08%, -0.32% | -0.71% | 0.77% | локальное наблюдение |
| exec-captures | -1.80%, +2.07%, +2.61% | +2.57% | 1.05% | не оценивается |

`many-captures`: 2000 замен строки из 8192 символов с named и optional captures; `no-captures`: та же серия без групп. `.test()` выполняет 20 млн вызовов, `.exec()` — 2 млн URL-разборов с шестью captures. Выигрыш одиночных test/exec не установлен. Предварительные короткие варианты сохранены отдельно.

Первый набор `no-captures` пересёкся со сторонней сборкой. Отдельный свежий повтор того же исходника и тех же бинарей содержит ещё 45 samples, ноль зарегистрированных compiler events; контроль Node между тремя сериями изменился на **1.59%**. Все исходные наблюдения остаются в JSON.

## Gate

- VM release **1272/1272**, JIT **292 ARM64 / 315 x86_64**.
- Runtime properties **16**, reclamation **6**, native context/body/append proofs **6**, обе архитектуры.
- Regex **39 unit + 47 интеграционных**, обе архитектуры; Clippy all-targets release `-D warnings` на обеих.
- Difftest **175/175** на ARM64 и x86_64.
- Test262 `full-2026-10-15c.json`: **53575 total / 52463 pass / 12 fail / 1100 skip** после валидации. Coverage и failure set совпадают с канонической базой; runner SHA записан сразу после полного прогона.
- RegExp Test262 до и после: **1962 total / 1943 pass / 19 skip**, без fail/timeout/crash.
- Checked CLI с verify, strides **1–16**: **8400/8400**, все **175** корпусов в interpreter/template/production; дополнительно capture regression **48/48**. Закрывающий журнал использует наблюдения одной неизменной сборки; source и binary SHA проверены.
- Новый корпус совпадает с Node в шести release-режимах; родительский release CLI stress1 также совпал с Node.
- Oracle **88**, GC **26**, full-GC **52**: все сравнения прошли.
- Source freeze **23** файлов; SHA CLI/runner/checked, logs и измерений сохранены в JSON.

Unit-проверки покрывают отсутствие name clones у borrowed views, одно удержание имён серией, независимость результатов от scratch и жизни шаблона, ограниченный сбор с продолжением поиска, точный prefix native captures, unmatched и duplicate groups. Новый JS-корпус проверяет callbacks с reentry и аллокациями, изменения протокола, indices identity, Unicode zero-width, split limits, legacy lastParen за девятой группой и идентичность исключения.

В первой полной checked-матрице этой сборки было **3 watchdog timeout**. Все точные условия повторены последовательно с тем же watchdog 120 с, source и binary SHA после основной цепочки; времена: interpreter 26.18 с, production 24.81 с, template 24.27 с. Закрывающий журнал объединил 8397 уже завершённых успешных наблюдений и 3 успешных повтора: всего 8400. Исходные timeout, stdout/stderr и полный первоначальный журнал сохранены отдельно без правок.
