# Array.push: один append в зарезервированный slab

Целевой gbemu в трёх повторных сериях: **−6,14…−7,20% wall**, инструкции **−7,07%**; разброс контрольной медианы Node **2,10%**. Запись в `array[array.length]`: **−23,94…−24,30% wall**, инструкции **−18,61%**, три серии по пять процессов на бинарь.

Устойчивое ускорение прямого push не установлено: числовой вариант **−5,96…+2,33%**, tagged **−0,50…+0,80%**. Все серии и samples сохранены; эти варианты отмечены `scoreable: false`.

Полная матрица: наблюдаемое геосреднее времени Otter **+0.43%**; FW **-0.391%**. Контроль Node/Bun изменялся от **-23.49% до +11.19%**. Общий wall-выигрыш не установлен; широкие wall-дельты помечены `scoreable: false`.

## Механизм

База: `6cfc6474`. Удалён повторный вход spare-capacity leaf в общий push с резервированием. Одна payload-проверка доказывает отсутствие sidecar, совпадение logical/dense length, свободную ёмкость и dense-size cap до первой записи. Именованный expando не влияет на индексную запись после разрешения callable. Прототипный indexed protector по-прежнему доказывает вызывающий код. Любой отказ предшествует эффектам; рост и особые свойства обслуживает существующий committed owner.

`ArrayBody::push_dense` заменяет `body_elements_push` во всех владельцах dense append. Slab сначала записывает значение и публикует live prefix, затем массив обновляет только cached length/kind. Адрес, ёмкость и receiver state не меняются, поэтому их повторное чтение и перепубликация удалены. Numeric-to-tagged widening, hole bitmap, dirty interval и запись барьеров массива/slab остаются у прежних владельцев. Новых ABI, флагов и параллельных реализаций нет.

Три unit-теста проверяют exact -0/NaN, holey/packed/tagged переходы и полный кеш, отказ без записи для full buffer/logical gap/readonly length, а также реальное перемещение молодого объекта, удерживаемого только старым slab после закрытия child handle scope. Два runtime-теста подтверждают normal-policy native execution, узел ArrayPush в основном realm, неизменную generation, отсутствие interpreter dispatch и точный однократный collecting callback после spare append и роста. Дополнительный realm проходит свой текущий путь. Новый difftest-корпус покрывает keyed append, named expando, рост, young aliases, holes, readonly/frozen/nonextensible массивы, prototype setter, замену push, sparse tail и Proxy.

- Runtime properties **16**, reclamation **6**, native context/body/append proofs **6**, обе архитектуры.
- Regex **33 unit + 47 интеграционных**, обе архитектуры; Clippy all-targets release `-D warnings` на обеих.
- Difftest **174/174** на ARM64 и x86_64.
- Test262 `full-2026-10-15a.json`: **53575 total / 52463 pass / 12 fail / 1100 skip**, **0 crash/timeout/OOM** после валидации. Canonical coverage и failure set совпадают с `14h` и `11e`; runner SHA записан сразу после полного прогона.
- Array.prototype.push: **24/24 до и после**.
- Checked CLI с verify, strides **1–16**: **8352/8352**, все **174** корпуса в interpreter/template/production; дополнительно append regression **48/48**. Journal свежий, source и binary SHA неизменны.
- Новый корпус совпадает с Node в шести release-режимах; родительские release и checked CLI stress1 также совпали с Node.
- Source freeze **8** файлов, hashes CLI/runner/checked, logs и измерений сохранены в JSON.

Oracle **80**, GC **26**, full-GC **50**: все сравнения прошли.
