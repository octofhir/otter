# Shape dependencies: optimized code subscribes to facts instead of re-reading them

Parent `b68511a00`. Machine provenance: [gate-summary.json](gate-summary.json),
[performance.json](performance.json), wall-clock `wall-final/`.

## Удалённый механизм

Оптимизированный код заново доказывал в рантайме три монотонных факта —
перед каждым использованием и снова после каждой операции, которая могла
выполнить код:

- **стабильность формы** (`CheckStableShapes`): байт stable каждой формы;
- **сводку типа поля** (`CheckFieldTypes`): младший байт field-type слова
  определяющей формы;
- **validity-ячейку прототипной цепочки** при загрузке наследуемого метода
  (`LoadGuardedMethod`).

Каждая проверка — материализация 64-битного адреса, загрузка и сравнение. В
richards на них приходилось 18% сэмплов изолята (CheckFieldTypes 6.7%,
CheckStableShapes 3.9%, LoadGuardedMethod 7.6%), в deltablue — 16%.

Теперь это зависимости кода:

- **Установка.** Поколение несёт `CodeDependency` видов `ShapeStable`,
  `FieldType` и `PrototypeValidity`. Реестр проверяет каждый факт и
  подписывает на него set-once флаг поколения:
  - формы — через список подписок, принадлежащий реестру; на него указывает
    `ShapeBody` (байт `watched` + указатель);
  - validity-ячейки — через список подписчиков самой ячейки.

  Факт, нарушенный между снимком и установкой (фоновая компиляция), делает
  компиляцию устаревшей (`JitInstallError::DependencyChanged`): tiering
  переармируется, а не записывается отказ.
- **Писатели.** Каждый писатель, нарушающий факт, ставит флаги подписчиков без
  контекста изолята:
  - `note_left`, `set_field_type_snapshot` и инвалидация validity — из Rust;
  - generated-писатели проверяют бит `watched`:
    - графовый `PublishShape` уходит в cold-stub `SHAPE_LEFT`;
    - template IC/actions уходят на miss до записи значения;
    - inline-расширения null/undefined/Top уходят в slow path observe.
- **Генерированный код.** Пасс `dependency_checks` после построения графа
  собирает факты доказательств, которые пережили builder. Затем он оставляет
  один тест флага (`CheckDependencies`: `ldrb`+`cbnz`) там, где факт впервые
  используется после входа или после узла, способного его нарушить, и
  удаляет остальные доказательства. Загрузки наследуемых методов больше не
  читают validity-ячейку: перед первой в регионе стоит тест флага.
- **Устаревшие поколения.** Сработавшие поколения реестр считает. Интерпретатор
  при выборе входа снимает их и заново армирует tiering их функций.
  `ExitReason` `StabilityChanged` и `FieldTypeChanged` заменены одним
  `DependencyChanged`.

  - цикл сам расширяет сводку, которую читает;
  - холодный код уводит экземпляр конструктора со стабильной формы.
