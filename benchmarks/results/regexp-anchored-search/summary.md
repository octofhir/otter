# Якорный поиск для sticky RegExp

Родитель: `f965e928`. Тулчейн: rustc 1.99.0.

## Изменения

- `otter-regex`: `Matches::anchored` — поиск пробует только свою позицию.
  Первый неуспешный кандидат завершает поиск без сканирования дальше,
  в обоих тирах: нативное окно `start..=start`, интерпретатор — один
  `Scan::Exact`. Повторные совпадения начинаются ровно в конце предыдущего
  (семантика `gy`). Префильтр и `^` отсекают кандидата до запуска матчера.
- Старт поиска в режиме `u`/`v` между половинами суррогатной пары
  нормализуется на начало пары; прежняя копия этой логики в
  literal-сканировании заменена общим хелпером.
- VM: `JsRegExp` сам передаёт `sticky` из флагов тела в `find_one` и
  `find_batch`. Фильтры «найдено не в `lastIndex` — отбросить» в
  `exec`, прямом `exec/test` и `test` без результата удалены: якорение
  целиком принадлежит движку.
- Тесты: 4 юнит-теста (свойство «якорный результат = leftmost, если он
  начинается в позиции» для всех стартов, ширин и тиров с равными
  шагами; отсутствие сканирования после промаха; бюджет шагов в самой
  позиции; конец строки и пустые совпадения; нормализация пары).
  Новый корпус `regexp_sticky_anchor.js`: катастрофический хвост,
  `y/gy/u/v`, `^`/`m`, lookbehind, пустые совпадения, coercion `lastIndex`,
  read-only `lastIndex`, legacy-статики, `split`/`replace`/`match`,
  подменённый `exec`.

## Поведение

- `/x(a+)+b/y` на `"zx" + "a".repeat(32)`: parent не завершается за 10 с
  ни в одном режиме; current — 0,02 с во всех трёх, Node — 0,03 с.
- `lastIndex` внутри суррогатной пары для `u`/`v`: 63 случая совпадают с
  Node (раньше 25 расходились). Нормативная формулировка обсуждается в
  tc39/ecma262#128; ориентир — текущее поведение Node и Bun.

## Гейт

- Clippy host/x86; VM 1272; JIT ARM64 292 / x86_64 315; runtime 16/6/6/3
  на обеих архитектурах; regex 90 (43 + 47) на обеих.
- Difftest 177/177 на обеих архитектурах.
- Test262 `full-2026-10-15e.json`: 53575 / 52463 / 12 / 1100, 0 timeout;
  набор падений совпадает с 15d. Срезы: RegExp 1943 pass / 0 fail,
  String.prototype 1182 / 0.
- Oracle 104 записи (13 корпусов × 7 режимов + Node), GC 26, full-GC 56.
- Checked GC 8496/8496 (177 × 16 × 3) с первого прогона, freeze неизменен.

## Замеры

3 раунда × 5 повторов, parent/current/Node с ротацией порядка.

| Нагрузка | parent, с | current, с | Node, с | current/parent по раундам |
|---|---|---|---|---|
| sticky-лексер | 0.0365 | 0.0339 | 0.0339 | −7.4%, −7.0%, −7.5% |
| non-sticky контроль | 0.645 | 0.635 | 0.174 | −0.8%, −2.0%, −2.9% |
| octane regexp | 1.592 | 1.595 | 0.405 | +1.2%, −0.4%, −1.2% |

Лексер короткий (~35 мс на процесс), абсолютное время в основном старт;
дельта устойчива во всех раундах. Non-sticky путь не замедлился; octane
regexp в пределах шума.
